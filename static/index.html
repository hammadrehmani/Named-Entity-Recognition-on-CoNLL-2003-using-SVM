Error Taxonomy & Linguistic Root Causes

Detailed breakdown of 1,987 misclassified tokens on the test set
53.6%

Entity Type Confusion (1,065 tokens)

Primary Cause: Polysemy and metonymy. National names in sports reporting are labeled as ORG or PER in gold annotations (*e.g., "JAPAN GET LUCKY WIN"*), but the linear model classifies them as LOC.

22.2%

False Positives: O → Entity (442 tokens)

Primary Cause: Sentence-initial capitalization mimicking proper nouns (*e.g., "Defender Hassan..."* where "Defender" is an occupational noun, not an entity).

19.2%

False Negatives: Entity → O (382 tokens)

Primary Cause: Rare, foreign, or out-of-vocabulary named entities that lack recognizable morphological suffixes and appear without strong contextual cues.

4.9%

Boundary Confusion: B ↔ I (98 tokens)

Primary Cause: The token-level SVM classifies each token independently without a transition matrix (Markov property), occasionally mislabeling consecutive entity tokens.

Pipeline Specifications & Mathematical Details

Algorithm

Linear Support Vector Classifier (LinearSVC via LibLinear coordinate descent)

Primal Formulation

$\min_{\mathbf{w}} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum \max(0, 1 - y_i\mathbf{w}^T\mathbf{x}_i)^2$ with $C=1.0$

Feature Space

76,004 dimensional sparse binary vector per token ($L_2$ regularized)

Context Window

Bi-directional 3-token context window ($[-1, 0, +1]$) with lexical, affix, and POS features

Training Runtime

58.28 seconds on 203,621 tokens (single CPU core, 0 GPU requirements)

Tagging Scheme

Standard 9-class BIO representation (PER, ORG, LOC, MISC, O)
